# UI/UX 跨模块梳理与统一

用户日期：2026-10-22。最终应用构建 `2de6ac53acd04522`；版本不变，未打包、
推送或修改冻结归档。保留其他工作区改动与用户资料。

## 统一准则

- 普通选项不使用常态外框线，选中、悬停、禁用以填色/文字/透明度表达；危险操作
  仍保留明确文字、危险色和确认。面板分区线、非交互键帽不是选项，按语义保留。
- 普通工作区操作 32px，嵌套行内图标操作 28px。分段组外高 32px、内部项 28px；
  不强迫不同文字等宽，不统一重置视频/原生窗口的专用控制栏尺寸。
- 字段与说明使用已有深浅语义色、圆角和字号，图标沿用离线 Lucide 家族。
- 键盘 focus-visible、原生 checkbox 语义、状态文字、错误/加载反馈不能为追求
  无边框而消失；原有快捷键、草稿保护、危险许可与取消时机保持。

## 核查和实施

| 模块 | 本轮发现/处理 | 行为边界 |
| --- | --- | --- |
| 媒体库、目录树、分页 | 复查既有无边框、焦点、尺寸、窄窗规则 | 不改查询、扫描或缩略图策略 |
| 片单 | 清除选中项遗留描边；普通动作 32px、行内动作 28px；输入/搜索统一填色；焦点行保留背景 | 不改顺序、连播范围、多选或撤销 |
| 数据备份 | 缩略图选项复用 SettingToggle；文件选择和校验预览成组 | 不改备份校验、恢复提交与取消保护 |
| 备份键盘入口 | 原隐藏 file input 的 label 不可聚焦；改为标准 Button 激活原生 input | 保留文件类型、忙碌禁用、选择/清空处理；没有自建文件读取服务 |
| 存储清理 | 旧副本选项复用开关，说明仅预览仍需确认；统计从嵌套卡片改为分隔行 | 不改 token、文件归属、活跃保护或二次确认 |
| 回收/文件记录、批量区 | 减少逐项框线，统一工具栏背景/按钮尺寸和表单说明 | 不改精确身份、选择上限、停止/恢复/永久删除授权 |
| 帮助/关于 | 帮助分段选项无描边、嵌套项等高；模式选择按统一字段呈现 | 阅读其他模式不写播放偏好；不自动检查更新 |
| 运行诊断 | Activity 图标取代通用信息图标；字段字号、间距与分隔行一致，长路径仍换行 | 不改采集、导出或隐私提示 |
| 播放器 | 设置下拉控件无常态外框；回归全屏、弹层和焦点状态 | 不改画面/解码/质量/源重载/MPV 窗口行为 |

修正两项旧测试的预期主题 token：片单重命名输入框按新规范使用 ui-raised，
不再使用旧 ui-field。危险悬停、对比度、尺寸和行为断言保留，没有删除安全断言。

## 证据与边界

本轮不是声称所有历史 CSS 已全部移除。现有 Mira 兼容层仍与特性样式共存；
此次以模块边界限制覆盖，避免对播放器画面、原生叠层和文件逻辑做大范围重置。
后续可在有回归保护时逐模块消除死规则，不做无证据的整库删除。

真实 Electron 脚本补充数据管理、帮助/诊断与备份/存储滚动截图；组件测试新增
深浅/390px/1440px 的跨模块检查及键盘 Enter 激活文件选择。备份/恢复与回收
写操作测试均使用测试服务的隔离数据，不操作 E:\downloads。

已只读复测授权 4K AV1 原片，早期本轮构建报告：
`build/original-startup-hgbuPu/report.json`。两种音轨记忆状态均原文件直放、
3840×2160，15/35 秒真实呈现帧通过，源哈希/大小/修改时间不变。起播统计仍有
丢帧，不能据此宣称 4K60 全程无丢帧；最终构建的复测另记录。

桌面高 DPI 实测发现错误卡片 bounding rect 为 480.0000305175781 CSS px，
computed width 为 480px，DPR 1.75。断言保留 480px 设计上限，仅允许 0.1 CSS px
的小数误差，并输出实际几何值；没有修改应用尺寸或掩盖布局溢出。

完整多屏 DPI、MPV 原生叠层/HDR 物理显示验收仍不在本轮已确认范围；不把浏览器
组件回归当成这类桌面验证。未重新运行完整后端套件，也没有打包发布。
