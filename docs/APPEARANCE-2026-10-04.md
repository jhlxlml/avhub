# 明暗主题与封面大小（2026-10-04，未打包）

## 实施前评估

两项都属于展示偏好，不需要更换播放器、改变媒体 API 查询、扫描、视频流或数据库媒体表。使用已有 SQLite 偏好保存接口，只增加经过白名单校验的 `appearance` 键。

封面尺寸不能与“每页数量”混为一谈：变大后每行更少、页面更长；紧凑时可能有更多懒加载图片进入视口。保留分页上限、单视频悬停预览，不一次载入整个库，也不重新生成缩略图。放大低分辨率封面不会提高其像素，更不影响原视频画质。

## 使用

- 顶栏设置按钮左侧增加太阳 / 月亮图标，一键切换浅色 / 深色。播放页标题区同样提供入口，纯净播放不增加常驻浮动按钮。
- 封面墙 / 列表切换左侧增加封面大小图标，展开四档滑块和快捷按钮；Esc 关闭并返回按钮焦点，点击外部关闭。
- 默认深色、标准大小；主题和大小在当前媒体库中持久化，保存失败沿用现有通知、重试与退出保护。浏览器缓存仅用于预热，SQLite 为权威来源。

| 尺寸档位 | 卡片最小参考宽度 |
| --- | --- |
| 紧凑 | 160px |
| 标准 | 190px，与此前默认网格相同 |
| 舒适 | 240px |
| 宽大 | 300px |

实际卡片宽度随容器均分；窄于参考宽度时允许单列缩小到容器宽度。保持 16:9 封面，不拉伸图片。

## 功能边界与实现

- 新建独立展示状态，修改根节点的主题与尺寸属性。没有将它加入筛选状态或查询依赖，不因拖动滑块重新获取索引，也不卸载、重挂媒体卡片。
- 普通封面墙、电影、收藏、历史及剧集分组共用大小规则。列表模式禁用调节入口，保留已选档位；列表封面、单集行和播放队列不改变尺寸。
- 浅色覆盖导航、表单、对话框、片单、诊断、播放器外部信息与原生标题栏；补齐旧样式中固定颜色的标题和说明。
- 视频容器保持独立深色高对比变量：透明控制栏、文字字幕和原生纯净播放浮层不随浅色主题变成白底，也不对视频应用滤镜。明暗切换保留同一 video 节点、同一播放地址和暂停状态。
- `appearance` 仅允许 `theme: dark/light` 和四个 `coverSize` 枚举，拒绝额外字段与无效值。没有新增数据库表或媒体文件写入。
- 设置使用现有数据库备份与保存队列；桌面退出会等待偏好提交，跨随机端口重启从数据库恢复。
- 320px / 390px 窄窗口下，大小弹层按整个视图控制区右侧定位，避免向左超出窗口。
