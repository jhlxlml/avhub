# 回收与恢复入口精修

## 交互

- 单文件回收成功后显示十秒提示，包含“恢复视频”及“查看回收记录”。悬停、键盘焦点或恢复进行中暂停倒计时；错误保留，转到完整记录核对，不自动重试。
- 快捷恢复绑定主进程返回的精确 operation_id，不通过标题、路径或“最新一条”猜测。回收结果不明确时不展示成功恢复入口；旧桌面组件缺少记录 ID 时保留普通提示及完整记录入口。
- 工具栏保留原“回收记录”，右侧增加统一图标的“最近回收”小面板，最多显示六条。可逐项恢复、查看异常状态或进入完整列表；不自动勾选，不提供永久删除快捷操作。
- 批量回收完成关闭结果窗口后，提示中只提供记录入口；多个文件的恢复继续使用完整列表的选择、预检和确认流程。仅单项成功时允许同样的单文件快捷恢复。
- 不新增全局 Ctrl+Z，避免与搜索输入、文件名编辑及其他文本撤销冲突。

## 安全与实现

继续使用原有 Windows 系统回收站、SQLite 操作记录及 Windows 原生恢复接口，不解析或手工移动 $I/$R，不保存视频回收副本。快捷恢复复用单项预检 token，检查清单 ID/action/eligibility，执行后释放 token；目录授权、唯一身份、原位置占用、操作中断及待核对保护不放宽。

最近面板只在打开或手动刷新时查询，不增加持续回收站轮询；使用已有封面缓存，不从回收站中的大视频重新解码预览。深浅色、长文件名及窄窗口使用现有 UI 组件和主题变量。

新增 renderer harness 覆盖精确恢复、预检拒绝、结果不确定、批量范围和主题/窄窗口。真实 Electron 测试 `electron/test/recycle-shortcuts.mjs` 只生成并操作 GUID TEMP 样本，验收提示恢复、最近面板恢复、哈希及收藏/进度保留，永久删除权限始终关闭。

本轮不打包、不推送、不增加版本号。
