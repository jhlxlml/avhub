## 实际发现与修正

1. 长路径和重命名预览使文件操作弹窗整体滚动，滚至底部后标题与关闭按钮不再可见。文件操作及共享确认框改为弹性布局：标题、关闭和底部操作保持可见，仅正文滚动。
2. 重命名输入继承通用表单 360px 上限，宽窗口仍只能使用部分空间。仅解除文件操作区域的限制，字段现在使用正文可用宽度。
3. 确认框原定 480px 上限被后置通用 `.modal` 的 740px 规则覆盖。使用模块限定选择器恢复 480px 上限，避免改变其他弹窗尺寸。

保留原有确认按钮顺序、默认取消焦点、Escape、草稿保留、inert、忙时保护及可信文件操作代码；没有修改重命名、系统回收或恢复的执行逻辑。文件路径容器去除多余外框，与其他输入/详情区域协调。
