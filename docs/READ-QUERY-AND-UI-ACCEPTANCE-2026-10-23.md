## 按审查顺序完成的改动

1. Electron 精确升级至 44.9.3，锁文件同步；运行时版本与包版本一致。
   npm audit --audit-level=moderate 返回 0 告警。原有权限白名单继续拒绝
   pointerLock，没有为消除审计而放宽门禁或批准额外安装脚本。
2. 封面、片单分页/队列、偏好、诊断统计、随机下一条和剧集详情使用查询专用
   WAL 连接；多语句分页显式 BEGIN，保留恢复互斥门。自定义封面通过短时
   reader_lock 协调选择/打开与清理，流读取有自己的句柄，完成释放幂等。
   数据写入、提交成功语义、FULL 持久化和文件操作许可没有改变。
3. 片单前后项改为同一分页语句里的索引查找；搜索序号另用一个批量查询。
   返回不超过 4 条时批量计数，否则仅排名截至最后返回项的窄 ID 前缀。
   保留同 position 的 ID 稳定顺序、离线成员、过滤前全列表序号、孤儿排除，
   实际自动下一条仍跳过离线视频。
4. 目录权限、可用状态及视频文件操作信息不再静默吞掉读取错误。失败时保持
   写控件关闭，显示原因和局部重试；重试不自动授权、不自动执行文件变更。
   旧权限不会在失败刷新后伪装为当前值。错误文字与动作分区排列，窄窗换行。
5. 扫描取消全库媒体字典，按最多 128 个候选路径读取索引，再进入原有有界
   工作者队列。按路径匹配仍包括旧 root_id 记录，保留重叠目录和迁移识别。
   只保留必要的根目录 trie 与本次目录 found 集合，**不是声称全扫描内存恒定**。
6. 悬停预览起播/停滞等待期限为 8 秒；重复 stalled/waiting 不延长同一等待。
   超时、错误、隐藏文档或卸载会释放 src/解码器；保留原封面，不重试转码。
7. 样式基底使用共享语义颜色/圆角，移除不再使用的 hero、旧 root/add-root
   规则；新增状态沿用共享 Lucide、按钮和危险色。此次不是无证据地删光所有
   特性 CSS 或播放器/原生窗口兼容层。

## 回归中纠正的遗漏与负优化

- 第一版搜索全列表 ROW_NUMBER 虽减少语句，却使首页和单条搜索变慢，已撤回，
  最终采用所需前缀/少量结果批量计数，不以查询次数下降冒充所有场景加速。
- 剧集列表历史上会补齐未分组旧记录，初次只读改造导致 4 项旧库回归失败。
  已拆出“检查到缺失时才真实写事务补齐”；正常浏览 infer=False，不在只读
  连接中写库。对应 16 项旧库/剧集测试和最终全量回归均通过。
- 桌面长标题验收曾在点击返回后，保存和 history.go/popstate 尚未完成时重载
  播放 URL。现断言媒体库可见且 URL 不含 video 后再继续；没有延长原超时。
- 本轮真实桌面初次启动/退出后重启各出现过未进入媒体库的超时，不能据重跑
  成功宣称根因已消除。补充失败页面、页面错误和截图采集，最终完整重跑通过；
  若再次出现，可从保留证据定位，不将该项归因为已证实的 Electron 缺陷。
