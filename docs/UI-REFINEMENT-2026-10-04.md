# UI 精修与浅色模式协调（2026-10-04）

## 设计方向

保留密集、以视频为主的布局，不增加宣传区、侧栏或额外留白。浅色采用灰白页面、白色主面板、浅灰蓝输入/次级面板和少量珊瑚红强调；深色沿用相同层级和交互规则。视频画面上的控件保持独立的深色高对比配色，避免切换主题时改变视频视觉内容。

## 本轮梳理及修正

| 模块 | 修正 |
| --- | --- |
| 顶栏、搜索、筛选、分页 | 浅色顶栏使用白色表面；搜索移除重复的内层输入边框，由外层显示焦点；筛选悬停不再变深蓝；按钮高度、边框和选中状态统一 |
| 封面墙、列表、剧集 | 保持原封面密度、尺寸偏好、预览和缩略图；列表/剧集行使用同一表面与悬停；封面上的收藏和进度用固定明亮强调色，不继承浅色界面的较深强调色 |
| 设置四个分类 | 标签选中/悬停规则统一；窄于 420px 时改为两列，不挤压四个标签；数据统计、备份预览、诊断采用统一的次级面板 |
| 播放列表 | 选中片单保留强调状态；条目、移动按钮、重命名和移除悬停使用主题变量；危险操作用浅色语义底色，而非硬编码酒红色块 |
| 批量整理与封面任务 | 批量窗口标题补齐同系列 SVG 图标；任务统计、失败原因、空白及表单与其他窗口统一；保留原来的操作流程和忙碌锁定 |
| 播放页外部信息 | 快捷键、播放信息、字幕、音轨和媒体编辑共享面板层级；修正字幕延迟数字、诊断标签和长标题的可读性；封面辅助操作不再全部使用主按钮强调色 |
| 错误与保存状态 | 目录加载失败和媒体编辑提示复用共享状态组件；错误带图标、语义颜色及柔和底色，保存完成与错误不混用颜色；原有重试和校验逻辑保留 |
| 视频内部弹层 | 明确重设派生颜色变量：错误底色、强调边框、焦点阴影等不能继承浅色根节点已经计算好的颜色，确保弹层中的文字保持对比度 |

## 样式约束

- 共用 `design-system.css` 的表面、文字、边框、圆角、控件状态及语义颜色，浅色变量和视频区域边界在 `appearance.css` 中定义；没有新增第三套图标、远程字体或图片 UI。
- 主操作、次操作、危险操作分层；选中状态在鼠标悬停时不能被普通 hover 覆盖。
- 所有媒体图像保留原有内容。控制栏仍透明、无渐变及明边框；不恢复浏览器全屏，不改变已实现的键盘静默操作、悬停保持、暂停隐藏、滚动条显隐或截图快捷键。
- 样式变更不修改播放来源、解码实例、分辨率、转码策略、源视频或数据库结构。

## 验证方式

- `tests/ui/ui-refinement.spec.ts`：深/浅色逐模块检查正常、悬停、选中、焦点和错误状态；截图覆盖媒体库、四个设置分类、片单、批量整理、后台封面、剧集、列表及播放器信息/弹层。
- 字幕延迟与诊断标签检查文字色；正文辅助文字及危险文字检查对比度；在切换页面主题后制造视频弹层字幕错误，确认仍使用独立的暗色语义底色和可读文字。
- 检查 320 / 390 / 760px 下的页面及四个设置分类无水平溢出。对话框截图使用实际视口，避免全页截图把视口外背景误认为未覆盖区域。
- 复用目录、批量、预览、封面、截图、播放交互、滚动条及 Electron 窗口验证；测试数据库和视频均为隔离合成样本，不操作日常媒体目录。
