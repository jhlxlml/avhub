# 桌面视觉体系与媒体库样板验收

## 范围

按“设计基础 → 媒体库样板 → 其他模块 → 完整回归”的顺序，先完成前两步。
借鉴克制、清晰的层次和排版，保留 Windows 窗口习惯和高密度视频浏览，不复制
macOS 窗口按钮、不引入 Apple 字体/图标资源或新的 UI 框架。

- 深色改为中性炭灰，浅色改为中性浅灰与白色内容层，保留珊瑚色强调。
- 增加窗口 chrome、标准控件高度、封面圆角变量；统一共享圆角与柔和阴影。
  修改现有主题和组件规则，不新建一层覆盖所有页面的“换肤”样式表。
- 顶栏普通操作去除常驻描边，分类仍在 AVHub 右侧；保持清晰选中和键盘焦点。
- 工具栏分为“浏览与筛选”“媒体整理”两组，分辨率和视图仍在右侧。
  小窗口沿用紧凑分辨率入口和图标，并允许分组换行。
- 封面仍为 16:9，大小档位、列宽算法、分页数量和懒加载不变；没有为美化扩大
  两侧留白、加入大标题、遮暗悬停视频，或增加动态玻璃/视频表面滤镜。
- 修正原生播放旧样式中未定义的 `--ui-text-muted` 引用；不改播放器控件行为、
  视频表面的原有深色对比规则、原片/无损策略、MPV 布局与解码逻辑。

本阶段的共享色彩自然作用于设置和片单等模块，但没有声称这些模块的信息结构
已全部重做，也没有完成所有旧样式的清理。后续逐模块推进，避免一次改动过大。
