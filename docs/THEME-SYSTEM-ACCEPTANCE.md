# 外观与主题首轮实现、验收

2026-10-24，开发版本 0.2.16，最终构建 `dd33cd5aeba2ab2e`。
本轮没有打包、发布、推送或升级版本号；历史网页归档不变。

## 功能与设计

- 设置增加“外观”分类，使用同一套 Lucide 图标、32 px 操作控件及无明边框的选项。
- 紫色、蓝色、青绿色、暖橙、石墨灰五套预设；取色器与 `#RRGGBB` 可自定义主题色。
- 浅色、深色、跟随系统独立于配色；背景可选中性灰、冷灰、暖灰，强调程度为柔和/标准。
- 使用现有共享 CSS 变量统一媒体库、设置、弹窗、标题栏与现有播放器；不改动媒体图像、
  封面文件、视频滤镜或解码设置。内嵌 MPV 的 Electron 控件读取已保存主题色；
  MPV 独立窗口 ASS 自绘界面也共用配色模型，始终派生深色控件，保留视频及字幕本身颜色。
- 从给定颜色派生文本、悬停、弱底色、选中底色及视频叠层的强调色。普通文本/选中
  文本及主按钮文字以至少 4.5:1 为检查目标；极亮/极暗自定义色自动适配，原始选色
  不被重写。色差或对比度测试不能替代真实显示器色彩、HDR 或辅助技术验收。
- 默认中性灰的主要背景与原有深浅主题一致；色彩只用于界面，不改变内容查询、排序、
  分页、封面大小或原画播放。切换主题不重建媒体卡片或视频元素。

## 草稿、保存与兼容

- 实时预览与已保存状态分离，预览不发偏好写请求；取消、确认放弃后关闭、组件卸载
  都恢复已保存外观。恢复默认先作为草稿预览，封面大小独立保留。
- 新增未保存修改保护，与既有设置关闭/退出保护合并，未保存草稿不被静默丢弃。
- 显式保存先等待已有偏好写入，然后写入本地 SQLite；设置接口在同一事务中读取
  实际接受的 appearance，提交成功后将其作为可选回执返回。客户端核对字段和值
  再更新缓存和显示成功，不把过期写入被忽略当成保存成功。
- 失败时保留草稿供重试，不把失败主题加入后台自动重试队列。切回旧外观不会偷偷
  再提交刚才的草稿。跟随系统由媒体查询事件驱动，不后台轮询，不自动写回主题模式。
- 旧 `{theme,coverSize}` 数据仍可直接读取/保存，客户端补齐缺省配色；新字段只允许
  固定枚举和六位 HEX。未知字段、CSS、URL、无效色值在批量写入前整体拒绝。
- 偏好仍在原 preferences 表中，随数据库备份和数据目录迁移保留；不新增媒体副本、
  数据库表或启动时整库迁移。顶栏快捷明暗切换继续自动保存，并保留自定义配色。

## 测试

### 配色、后端与组件

- `theme-palette.test.mjs` 3 项通过：旧值/坏值降级；5 套预设和 9 种极端自定义色，
  遍历两种明暗、三种背景和两档强调，共 168 组；检查文本/选中/按钮/叠层对比度，
  输出值为受控 HEX，派生过程不改写用户选色。原有样式归属契约另 1 项通过。
- `test_preferences.py` 18 项通过：新旧设置、严格颜色校验、原子拒绝、过期写入回执、
  扩展主题进入数据库备份。`test_full_backup.py` 11 项和 CI 契约 12 项通过。
- 主题、原外观、样式加载顺序、延迟设置模块等 23 项 renderer harness 通过。
  包括取消预览无写入/无查库/保留卡片，保存/重载、系统明暗事件，失败与过期回执，
  无效 HEX 关闭保护，恢复默认保留封面大小，视频身份/原画请求不变，以及 390 px 键盘导航。
- 设置一致性、滚动、Mira 导航与完整备份的补充 renderer 回归另 27 项通过，
  合计 50 项。它们是组件/行为测试，不冒充实际桌面播放性能结论。

首轮测试发现旧外观测试仍只预期两个字段，更新为包含新字段的严格期望；预设 radio
初版只暴露 1 px 原生输入命中区域，改成覆盖整张卡片的透明原生 radio，保留键盘
导航和焦点可见性。重新执行相关测试通过，没有使用强制点击绕过命中问题。

### 真实 Electron

`electron/test/themes.mjs` 在正常 GPU、安全设置下运行真实 Electron，生成 8 个
应用自有 H.264、640×360、12 fps 样本，单个约 12 秒；没有使用 `E:\downloads`。
验收包括：

1. 通过正式 API 扫描并生成封面，读取旧的两字段外观配置。
2. 从设置实际选择五套主题；核对派生色对比度，预览期间库查询次数为 0，媒体卡片
   身份保留，SQLite 中旧设置没有被预览覆盖。
3. 查看浅色/深色自定义配色、1440/1000/800 px 桌面布局；设置内容没有横向溢出。
4. 取消草稿后还原旧外观；保存自定义色、暖灰背景、跟随系统，保持原封面尺寸。
5. 正式播放生成视频，切换明暗后视频元素/来源保持同一身份，实际解码 640×360；
   仅一次原文件播放请求，无音视频转换许可，不称为性能/FPS 对照。
6. 正常退出、以同一隔离数据目录重启，再核对设置和 HEX 字段；源大小、mtime、
   SHA-256 一致，页面错误为空，再次正常退出。

## MPV 独立窗口主题适配

- 纯配色模型移至 `electron/src/themePalette.ts`，renderer 从同一实现导出；主进程严格校验固定字段和 HEX，不开放任意 CSS、Lua 或播放命令。
- 启动时将已保存配色写入应用自有 Lua。活动会话支持事件驱动同步、合并连续变化、预览取消恢复；同一配色不因状态推送反复发送，关闭或过期会话不接受更新。
- 只重绘 ASS 控件，未更改加载、跳播、音视频滤镜、分辨率或解码设置。深浅模式不改变原生视频控件的深色背景。
- `native-theme.test.mjs` 三项通过：输入边界、renderer 合并与取消、主进程序列化和会话隔离；共享配色三项及独立播放协调回归通过。
