## 源码修复

`playbackClock.ts` 管理一个成对申请／归还的 Windows 计时请求，供已验证 FFI 的 `RenderTextureBridge` 使用。

- 只在有播放意图、实际非暂停／非结束、所属窗口可见且未最小化时申请。
- 暂停命令、隐藏／最小化事件、错误、关闭、接收端失效及 drain 都会归还；窗口恢复后根据实际播放状态重新申请。会话关闭移除对应窗口事件监听。
- 不重复申请；申请失败仍走原有计时，不逐帧重试；释放失败保留“仍持有”的状态以供关闭重试，不能假报已归还。
- 保留原有 10ms 空闲轮询和 GPU 完成／读者释放检查。没有忙等待、提前复用纹理、编码转换、降分辨率、减位深或更改色彩。
- WinMM 是 Windows 系统 API，不向包中添加额外第三方 DLL。此项只影响原生嵌入链路，现有 Chromium 播放和独立 MPV 路径未改。

[微软文档](https://learn.microsoft.com/en-us/windows/win32/api/timeapi/nf-timeapi-timebeginperiod)说明调用必须同参数成对归还、可能增加功耗，且 Windows 10 2004 起按调用进程请求；Windows 11 对被完全遮挡／最小化的窗口不保证该精度。这里实测的是当前 Windows 11 单屏 SDR；不对旧 Windows 或所有遮挡／硬件组合作效果保证，不修改系统全局配置或注册表。
