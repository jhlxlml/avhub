# 选定的七项便利功能：独立实现与验收

构建 `f3a2aeabccb1dee0`。对应用户选择 1、2、3、4、5、9、10；未加入目录树、全部操作、改名或改变默认主题/数据目录。本轮未打包、未推送，不修改网页版归档。

## 交付

1. **原生目录选择**：桌面添加媒体目录、重新定位与截图目录通过受限 `avhub:choose-folder` IPC，由实际 Electron 主进程选择、realpath/stat 验证。渲染进程只传用途，不传默认目录或命令。取消不提交 API，桌面不调用 tkinter；浏览器原入口保留。对话框只允许选目录，不附带创建/删除视频目录功能。
2. **目录记忆**：媒体与截图分别保存在当前数据目录的 `avhub-directory-choices.json`。异步读取、16 KB 上限、版本/绝对路径检查、目录类型检查、失效降级、可选读取最多等待 1.5 秒；通过独占临时文件、sync、rename 原子保存。不跟随状态文件链接，不写视频目录，记忆失败不阻止选择。
3. **起播策略**：新偏好 `resumeBehavior`，只有 ask/resume/restart 合法。默认 ask 保持原行为；首次请求前一次计算位置，不在 effect 中先续播再回零。不论策略，已看完或完成的视频从头；自动连播不询问，resume/ask 续播未完成项。切换后经 API 确认持久值再更新界面；保存失败保持原选项。设置不清记录，不改变播放质量及转换权限。
4. **排序**：视频列表增加总像素与文件大小升/降序；CASE 统一将缺失/非正数变为未知，未知置后，id 稳定打破平局。增设四个 missing=0 的表达式索引；不硬性强迫有过滤查询使用全库排序索引，仅修复精确匹配的早期生成索引布局。
5. **卡片大小**：只格式化已有 size 字段，保留影片/剧集/历史的原元信息，追加紧凑大小。未知、非正或非法值不显示。不重新生成封面、不探测视频、不改变列宽与页面数量。
9. **数据目录工具**：数据管理页显示启动器已经选择的位置，支持打开/复制。没有引入选址迁移、portable-data.txt 或写入探针。桌面打开通过固定 appCommand，浏览器通过现有本机安全边界；目录均来自服务或主进程，不接受渲染进程任意路径。
10. **关于**：标题栏左侧 AVHub + 信息图标，及设置运行诊断入口。复用 Dialog/Button/Icon、深浅色变量，展示版本/构建/API，复制版本与项目地址。主页由固定枚举调用可信主进程打开，原 window-open deny 不放宽；保持 AVHub 品牌及原图标。窄纯净窗口折叠为信息图标，不挤出窗口关闭按钮。弹窗内不抢占播放快捷键；置顶按钮后的 W 等原行为保留。

没有复制/合并 MP4Hub 文件或提交。功能只借鉴用途；状态存储、API复用、初始请求决策、SQL索引、IPC边界及控件组合均按现有 AVHub 实现。冻结归档不参与构建。

| --- | ---: | ---: |

## 使用

- 源码版运行 `npm run electron:dev`，同时更新 renderer/backend/main；旧 EXE 不读取源码，本轮没有更新 EXE。
- 原生目录按钮直接使用新选择器；路径记忆自动保存。
- 起播方式在设置“播放偏好”；排序在媒体库“排序方式”；卡片显示已有大小。
- 数据目录在设置“数据管理”；关于在桌面标题栏左侧或设置“运行诊断”。
- 当前 SQLite 库、收藏、标签、播放列表、原画默认策略及 MKV 副本默认关闭均保留；归档、E:\downloads 和原视频未修改。
