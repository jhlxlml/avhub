## 修复

1. 缓存磁盘读写出错时，旧工作线程只标记错误，FFmpeg 可能仍在后台运行。现在标记失败、唤醒等待者并停止本任务编码器；即使退出等待异常，也释放进程保护和日志句柄。状态查询和后台维护均检查，首个清单生成前的持续大量报错不再漏检。
2. 实际强杀隔离媒体服务后，FFmpeg 未随清单管道断开及时退出，缓存日志仍被占用。Windows 每个播放编码器现在加入独立、未命名、不可继承的作业对象，设置 kill-on-close，服务被强杀时由系统结束其中的进程；不枚举或终止其他播放器。保护建立失败会停止刚创建的编码器并清理本任务，返回可诊断错误。[微软作业对象机制](https://learn.microsoft.com/en-us/windows/win32/procthread/job-objects)、[关联进程与嵌套作业条件](https://learn.microsoft.com/en-us/windows/win32/api/jobapi2/nf-jobapi2-assignprocesstojobobject)。Windows 嵌套作业适用于现有 Electron Windows 10/11 目标；非 Windows 保留普通限时退出，不宣称同样的异常强杀保证。
3. 实际 4K / 60 Mbps 填充样本配合 64 MiB 小缓存复现了发布停滞：只发布至 8 秒，却已达到容量目标，播放停在 7.75 秒，生成端和消费端互等。现在容量节流保留约 4 秒的最小发布余量；极紧张且临近缓存尾端时后向保留可收缩到约 2 秒，允许旧片段回收与播放继续。保留原编码/画质档位，不用降低分辨率或质量来规避压力。
4. 网页全量回归曾出现字幕恢复后丢失选择。核查并强化两个异步边界：字幕恢复完成前不把暂时的“关闭”状态写入偏好，失败保留原设置；已经离开的播放器迟到的偏好读取，不覆盖新播放器已缓存/待保存的选择。新增慢字幕恢复失败和旧读取迟到的确定性用例，覆盖再次进入视频后仍保留轨道与延迟。

容量仍是软目标，不是硬配额。该 15 秒填充样本的在途输出一度约 108 MiB，明显高于 64 MiB 预算的 48 MiB 目标；修复保证推进，不承诺超大 GOP 或在途输出不超限。极小预算下回看更容易重新取流，这是有意的缓存权衡。

## 隔离验证工具

新增 `scripts/soak-playback.py`：不导入应用数据库模块，使用新建临时目录；已有源文件仅交给 FFprobe/FFmpeg 读取。按时间模拟消费并读取分片，记录生成窗口、容量、节流、暂停与重开，最后确认编码器/线程退出和源文件大小、修改时间未变。默认合成样本另做前后 SHA-256；真实大文件需主动加 `--verify-sha256`，避免默认对 NAS 完整读取两遍。

它验证 FFmpeg 与缓存生产/消费，不验证浏览器解码、音画同步、真实 NAS 断连或完整 Electron 长时间播放。报告保存在 `build/soak-reports/`，文件名唯一不覆盖旧报告；可能包含源文件名及错误中的路径，分享前检查。

```powershell
# 默认合成源，1 分钟；不触碰用户媒体库
python .\scripts\soak-playback.py --seconds 60 --speed 4 --pause-every 15 --pause-seconds 5 --cache-mib 16

# 4K / 60 Mbps 填充样本，约 113 MB 临时源；不是现实影片或画质基准
python .\scripts\soak-playback.py --sample-4k --seconds 60 --pause-every 20 --pause-seconds 5 --cache-mib 64

# 用户自行指定真实 H.264 长片，正常速度运行 1 小时
python .\scripts\soak-playback.py --source "D:\Videos\长片.mkv" --seconds 3600 --mode remux

# 不兼容编码的质量优先转码路径（不改写源文件）
python .\scripts\soak-playback.py --source "D:\Videos\长片.mkv" --seconds 3600 --mode transcode
```

重封装选项只测试流生成，不证明任意编码可被浏览器播放；源文件消失时验证失败，不自动改动媒体库。`--temp-root` 可指定已有临时目录父目录以验证另一缓存磁盘，但工具不会故意填满磁盘或切断 NAS。Ctrl+C 进入任务清理，不应使用强杀此脚本替代清理测试。

验证工具也修复了早期验收条件：仅有分片读到过、编码器仍存活不足以算通过。现在累计检测非暂停期间的 15 秒无推进；暂停不会把累计停滞清零。早期 4K 报告 `20261003-100451-e0f8179f.json` 已标记 invalidated，不计入通过结果。
