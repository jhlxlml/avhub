# 状态同步与回收体验精修

- 扫描完成、单文件整理及回收记录变化通知设置中的文件状态、来源确认和操作历史刷新。来源读取失败时不显示旧操作清单或假空状态；成功刷新清除旧错误。
- 文件状态的“查看回收记录”按记录 ID 定位实际分页并聚焦高亮，不自动选择项目。记录已清除时保留明确错误，仍可浏览其他记录。关闭嵌套回收窗口不会丢弃设置草稿。
- 来源保留提示区分自动封面重新生成与自定义封面保留；系统回收说明同时介绍应用回收记录和 Windows 恢复入口。
- 保留 120 秒回收预检期限、逐项身份与权限检查及不确定结果停止策略。“继续未执行项”只处理当前页仍可操作的未执行项目，重新预检；涉及永久删除仍再次确认。不延长失效预检，不自动重放已成功或结果不确定的项目。失败项与未执行项分开处理。

## 验收边界

后端使用逻辑过期测试，不等待真实两分钟：过期请求不调用原生操作，重新预检才执行。渲染器测试模拟批量过期与重新确认；真实 Electron 使用新生成 TEMP 视频验证扫描时设置保持打开及回收恢复。用户视频不变。

正式包验收脚本 `electron/test/portable-release.mjs` 对 EXE 和解压 ZIP 分别记录启动阶段，并为独立生成的 10 秒 H.264 MP4 记录导航至真实解码帧的耗时、尺寸及帧计数，校验样本字节不变。GitHub Actions 保存两个 `startup-timings.json` 为独立测量附件。

本轮不打包；新版正式包测量尚未执行，不能用现有旧版本包或开发版数据宣称收益。该合成测试包含驱动/导航开销，不代表真实长 MKV、TS、HEVC/HDR 或随机跳播；没有清操作系统缓存。后续授权发布时再进行正式包验收。
