# 回收记录：安全边界与验收

## 日常使用

- 媒体库工具栏的回收站图标打开记录；恢复需要系统回收授权，永久删除需要独立的永久删除授权，默认关闭。
- 全选、反选只处理当前页可操作项目，默认不选中任何项。搜索、切页、刷新清空选择。
- 恢复所选仅处理可恢复项，恢复原位置、保留媒体信息，不覆盖、不自动改名，也不创建视频副本。
- 永久删除单独确认。批次预检展示实际删除数量；已恢复或已核对失效的记录只清除历史。
- 展示逐项成功、失败、跳过和未执行。停止等待当前项完成；结果不确定时停止后续项。
- 重试失败项重新预检和确认。待核对项必须先核对结果，不能直接再删。

## 中断与持久化

恢复、永久删除先提交 `recycle_actions` 意图，再提交 dispatched 状态，然后才调用 Windows。执行结果、媒体库和操作日志在同一数据库事务中完成。每条回收记录只能有一个未核对的活动意图。

重启只检查文件身份并更新元数据，不启动 Shell 桥接、不重放移动或删除。原文件在原目录且身份一致时可以确认恢复；尚未派发的操作且回收项目仍在时记录失败。已派发但没有完成结果，或超时/管道中断，即使项目还在，也保留待核对，不能直接再删。消失不等于永久删除成功：用户核对后可清理历史，但不将其声称为已成功永久删除。

导入备份中的未完成操作进入待核对，目录权限重新授权。磁盘离线、身份损坏、访问失败、同名冲突及链接路径均不能绕过保护。

## 性能与资源

- 系统枚举在文件、播放和扫描锁之外完成；只对正在整理的媒体建立 pending 保护，原视频质量链路不变。
- 浏览快照五秒内可复用；主动刷新强制核对。执行始终重新检查实际文件身份和权限。
- 批次预检有效两分钟、最多 500 项；桌面选择仍限定当前页。预检只保存身份和路径，不保存视频内容。
- Windows STA 桥接按需启动、每次生命周期仅编译一次，空闲二十秒关闭，退出应用关闭自有进程。协议错误和超时不自动重放请求。
- 普通 Shell 项缓存最多 4000 个；超出时仅为本批次至多 500 项建立短期租约，避免逐项完整枚举。原生回调再次核验身份、路径及目标冲突。
- 永久删除后的无引用封面交给现有受保护缓存清理机制，不直接删除可能被备份或其他记录引用的图片。

## 本地验证与限制

真实 Electron 验收使用唯一命名的 TEMP 合成 H.264 视频，不触碰用户媒体。已验证：原目录恢复、中文/emoji 名称、同名冲突、默认权限边界、取消确认、仅删除所选项目、无关回收项保留、恢复后的 SHA-256、桌面批量恢复及真实进程退出。

六项原生恢复实测约 0.56–0.75 秒（含批次预检，不含人工确认等待），批次枚举一次，短期租约无需额外枚举，复用已有桥接进程。这是小型隔离样本结果，不是大文件、所有磁盘或生产回收站的性能保证，也没有据此宣称相对旧版提升倍数。

元数据测试桩包含 2000 条隔离记录：浏览 120 条并预检 500 条约 1.9–2.4 秒、读取快照两次。它不运行真实 Shell 删除或恢复，不能替代大规模真实环境验收。

回归覆盖执行前/后中断、数据库提交失败、离线模拟、权限撤销、身份变化、损坏日志、超时不重放、缓存孤立项、实时停止、重试重新确认、深浅色与筛选收纳。实际跨磁盘热拔插、杀毒软件拦截及操作系统断电属于尚未进行的实机故障注入，不以模拟测试冒充。

开发验收：`npm run test:electron:recycle-records`。渲染器用例是明确的界面桩，桌面接受度以实际 Electron 为准。CI 配置包含这些回归；云端结果由用户自行确认。
