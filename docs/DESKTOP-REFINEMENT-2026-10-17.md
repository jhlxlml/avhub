# 桌面播放精修验收（2026-10-17）

本轮只迭代源码，不打包、不推送、不发布、不升版本号。历史网页归档冻结；
E:\downloads 仅用于显式授权的只读播放与索引克隆，文件操作测试仅使用隔离样本。

## 实现范围

1. 窗口：分数 DPI 下的客户区校准改为等待原生尺寸提交后有界修正；新请求取消旧修正。
   纯净展开还原直接恢复已拟合矩形，不再对舍入后的面积重复拟合。IPC 等待校准结束。
   主窗口移动/缩放时，原生显示区域保留最新布局；设置中可复制去路径、去标题的播放诊断。
2. 每视频记忆：SQLite 的 `playback.<id>` 保存源指纹、FFmpeg 绝对音轨索引、字幕标识和延迟。
   MPV 在恢复播放前按真实 `ff-index` 映射，不能把 MPV 轨道 ID 当成 FFmpeg 索引。
   两套引擎共享记忆；源文件、轨道布局或外挂字幕变化后旧状态不再应用。
   库外临时字幕及无法可靠映射的轨道仅当前会话有效，音量/速度/字幕外观仍为全局偏好。
3. 验证：真实 Electron 嵌入测试、并发长测、真实封面快速滚动，与 renderer harness 分开统计。
   不以隐藏提示、暂停旧帧、MPV 时钟或单纯 JS 堆占用代替真实解码、I/O 和进程内存测量。
4. 工程：补充可重复原生测试命令，手动 CI 输入 `mpv_validation` 只做原生运行库回归，
   不进入打包与发布。更新双语使用说明，不在 README 写逐版本更新日志。

## 封面对照发现

只读克隆真实媒体库：2178 个视频、2178 张既有封面，每页 96 项，软件 GPU 的真实 Electron。
36 轮往返、翻页：

| 策略 | 请求数 | 最大挂载图数 | 渲染进程工作集，首→尾（KiB） | 长任务 |
| --- | ---: | ---: | --- | ---: |
| 移出视口即卸载 | 3056 | 42 | 264720 → 896332 | 0 |
| 测试专用原生懒加载对照 | 2274 | 96 | 274804 → 807228 | 0 |
| 附近首次加载、页内保留（最终构建） | 3241 | 96 | 248112 → 809412 | 0 |

报告分别为临时隔离目录 `avhub-cover-stress-3xYaqX/covers.json`、
`avhub-cover-stress-XKAxH8/covers.json`。这是有竞争负载的单机观察，不是冷缓存 FPS 基准。
JS 堆回落不能证明解码缓存已释放；上表显示激进卸载存在请求和内存负优化，不能只凭挂载数宣称成功。

最终策略保留首次附近加载，已加载图片留到有界页面卸载，减少页内重复解码；
报告 `avhub-cover-stress-3nP8QW/covers.json`。同口径尾值较激进卸载下降约 10%，
但仍约 790 MiB，逻辑请求数没有下降。请求事件不等于实际网络传输字节；
不能据此声称解决所有封面内存问题或减少跨页 I/O。需继续分离浏览器图像缓存测量。

## 人工验收与发布边界

- 用户间歇黑条没有稳定复现；已有只读实片复测正常，不据此宣布唯一根因。
- 真实多屏混合 DPI、不同 GPU/HDR/10-bit 显示仍需交互桌面验收；缺少样本的项目保留未验证。
- MPV 离线运行库摘要校验通过，但 `distributionReady:false` 保持不变：持久发行输入、
  完整许可及源码材料和硬件显示验收仍是发布门槛。本轮没有触发云端 CI。

## 下一轮优先级

1. 封面缓存：补真实传输字节/缓存命中、解码缓存和 GPU/渲染进程分项，拆开页内往返与跨页；
   在相同可见窗口与缓存条件下确定可重复的内存上界后，再改缓存策略。
2. 多屏实机：重点验收 100%/125%/150% 间移动、旋转后进退纯净、最小化恢复；
   若偶发黑条再现，立即复制播放诊断并记录步骤，避免只凭过后正常画面推断原因。
3. 固定回归：延长同构建、同条件的长时间原生负载，区分冷/热缓存；现有缺少的长 HEVC、HDR
   样本继续标记未验证，不用合成 SDR 样本替代真实色彩验收。
