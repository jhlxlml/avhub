# 视频截图体验优化（2026-10-03，未打包）

## 使用方式

1. 打开“媒体库设置 → 播放偏好 → 视频截图”。
2. 默认保存在**实际应用数据目录下的 `screenshots/`**。设置页显示实际完整路径；首次截图时创建目录，单纯打开设置不会创建目录。
3. 可以浏览并选择一个已存在的本地目录或手动输入完整路径。选择目录后点击“保存截图设置”，不会把该目录加入媒体库。点击“使用默认目录”仅清空草稿，仍需保存才能生效。
4. 快捷键仅保留 **C**（2026-10-04 调整），取消 F8 / Shift+S 和快捷键选择。输入框、编辑媒体信息、设置对话框和菜单中不触发。旧快捷键设置读取时统一为 C，原保存目录保留。
5. 播放时点击相机图标或按快捷键，直接保存 PNG，不弹保存/目录选择窗口，不暂停视频。截图反馈显示分辨率和文件名；桌面版可以在资源管理器中定位，浏览器版可复制保存目录路径。

完全退出旧窗口，在项目根目录运行 `npm run electron:dev` 体验源码新版。本轮没有打包，已有 EXE 不包含这些更新。

## 保存策略与边界

- 保存当前浏览器**解码画面**：按 `videoWidth × videoHeight` 绘制，不按播放器窗口尺寸缩小、不二次 JPEG 压缩、不含控件或文字字幕。CSS 旋转、放大、拖动画面不改变截图内容；硬字幕属于视频画面，会保留。
- PNG 是截图像素的无损压缩，不代表取到了原始视频码流帧，也不保证 HDR/10-bit 原始色彩、元数据或宽色域无损保留。转码播放时保存的是当前转码后的解码画面。
- 文件名包含视频标题、播放时间（毫秒）、截图时间与唯一标识；排除文件名非法字符，用独占创建保护已有文件，重复请求使用同一标识时不会重复写图。
- 自定义目录离线、权限不足或磁盘满时明确失败，不静默改存其他目录。PNG 完整性、CRC、解压后大小与像素数校验在后台线程执行；上传上限 128 MiB / 6400 万像素。暂存文件在正常请求结束时清理，不接触原视频。
- 截图请求不自动重试。若响应丢失，可点击“检查保存结果”；临时结果记录最多保留 100 条、1 小时，服务重启后不保留记录，但**不会删除已保存 PNG**。无法查到记录时请查看实际保存目录。
- 截图快捷键不让隐藏的控制栏显示。按住快捷键不会连发，未完成时不创建第二个截图请求。截图跨切片继续保存，Electron 正常退出会等待未完成任务；仍遵循原有 5 秒退出保存期限及显式取消/放弃提示，不能保证强制终止或断电时的未完成截图。
- 设置存入 SQLite，可随现有数据库备份保留；**用户截图文件不属于应用缓存，也不包含在“完整媒体库备份”中**。迁移时需另行保留截图目录；自定义绝对路径失效时重新选择。
