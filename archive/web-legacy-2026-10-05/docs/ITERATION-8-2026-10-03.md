## 1. 播放期间减少无效负载

- 控制栏隐藏时，播放时间保存在引用中，不为每次 `timeupdate` 重绘整个播放器。鼠标显示控制栏时同步实际时间；键盘跳播、暂停保存、画质/音轨切换仍使用最新位置，不用隐藏 UI 的旧时间。
- 播放状态发送短期活动信号，后台截图暂时让路；暂停或离开后恢复。信号 8 秒更新，20 秒过期，最多 128 个活动窗口，不写入用户的手动暂停设置。取消正在进行的截图后保留其持久任务，不将取消记作截图失败。
- 封面状态不变时不重复更新 React 状态，让路期间降低快速轮询。原片 / 重封装 / 兼容转码决策、输出尺寸与质量参数没有因此降低。
- 增加可见原生窗口、1×、5 秒预热的测量方式，记录呈现帧、长任务、进度 DOM 更新和进程 CPU/内存。GPU 功能开启不等于每种编码使用硬件解码；测试专用 `--in-process-gpu --no-sandbox` 不进入正式窗口配置。

## 2. 应用存储与预览后清理

- 设置“数据管理”按数据库、缩略图、手动封面、临时字幕、播放缓存、备份暂存及其他数据显示文件数/逻辑字节大小；不读取视频内容，默认不自动清理。
- 清理只认已知派生文件：孤立的数字 ID JPEG、超过一天的已知字幕临时文件、归属已失效且无活动会话的本版播放缓存。保留当前截图引用、待截图 ID、保留回滚库的截图引用、所有手动封面、未知文件和链接。
- 即使原视频被索引到应用缓存目录中，当前库及保留回滚库记录的源路径也排除在候选外。
- 回滚数据库默认全保留；只有勾选额外策略时，才预览超过 30 天且不属于最近 3 份的已知恢复前数据库，并要求第二次不可撤销确认。读取回滚库失败时，保守保留孤立截图。
- 确认携带基于候选路径/大小/修改时间的摘要；服务端在扫描、播放、截图及数据库保护锁内重新计算。不匹配返回 409，不重放删除；每个文件删除前再次核对，占用或变化的文件跳过。
- 不递归删除缓存目录，只删除识别出的文件，再移除确实为空的已知目录。清理不可撤销；派生截图可以重建，已删除的回滚数据库不能重建。

Windows 实际链接创建验收因权限跳过；另用重定向路径模拟验证数据任务拒绝外部链接父目录，不冒充实际 junction/symlink 验收。仍可能受同一账户外部程序并发替换目录的文件系统竞争影响，不宣称针对恶意本地进程的完全隔离。

## 3. 设置、备份预览与后台进度

- 四个同风格标签页：媒体目录、播放偏好、数据管理、运行诊断。支持方向键/Home/End，保留输入首焦点、弹窗焦点保护、窄窗口内部滚动；存储及诊断按进入页面加载。
- 完整 ZIP 与旧数据库导出/恢复仍兼容。创建快照、校验、打包、上传和检查为后台任务；校验/打包显示真实条目进度，不用定时器伪造百分比。上传与最终提交只显示不定进度。
- 恢复先上传和校验，预览记录数、收藏/播放列表、封面引用、备份版本及前 20 个目录状态；预览不替换日常库，用户再次确认才提交。校验、打包、上传可取消；数据库安装及回滚阶段不能取消。
- 使用浏览器下载文件，不在 renderer 中加载整个多 GB Blob；先校验 16 字节 Range 前缀，不接受 HTML 冒充 JSON/ZIP/SQLite。下载请求 pin 在传输断开时也释放。
- 私有数据任务最多 8 个，单活跃任务，完成/预览空闲 20 分钟过期。到达上限时优先回收已失败/取消且没有下载占用的旧任务，反复取消不会锁死额度；成功下载仍保留。过期预览可以放弃并选择新文件。关闭时清理自有暂存；非正常退出遗留暂存目前计入存储但保守保留，不自动删除未知目录。
- 在刷新设置保存失败、提交被拒绝、网络结果不确定时，不重复提交恢复。尝试读取实际任务状态；结果不明时继续保护窗口并提供“重新检查恢复状态”，正常状态恢复后解除保护。
- Electron 在提交阶段的关闭仅提示等待/返回，不允许“仍然退出”；正常保存失败仍保留原有重试/明确放弃流程。修复设置弹窗遮罩/`inert` 拦截原生标题栏按钮的问题，标题栏在弹窗打开时仍可操作。

复制真实索引的新后台流程：1982 条记录、1981 张缩略图、一个手动封面；完整包 38121621 字节，生成 9.326 秒，校验加提交恢复 17.607 秒。预览与恢复数量一致，收藏/42 秒进度/手动封面保留，离线提示和重新定位保留元数据。源目录清点新增/移除/大小或时间变化均 0；不是 2.19 TB 全文件哈希。报告 `build/backup-migration-1791017398904618300/report.json`，构建 `3d4ee3b69d2d062f`；之后的改动为 UI 异常保护及清理源路径排除，备份格式/安装流程未变。
