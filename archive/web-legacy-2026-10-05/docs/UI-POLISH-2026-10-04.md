# 播放器全屏控件精修（2026-10-04）

## 原因与修复

- `fullscreenExit` 的旧路径右下角位于 x=14..19，其他角以 24px 图标网格中心镜像，造成不对称。改为四条独立、向内的角线，右下角恢复到 x=15..20。保留统一的 1.7px 描边、圆角线端和 20px 控件图标尺寸。
- 按钮原本只修改图标、提示及 `aria-pressed`，辅助名称一直是“全屏”。现在全屏时名称为“退出视频全屏”，退出后恢复“全屏”。
- Esc 原本依赖宿主的默认退出行为；新增显式调用 `document.exitFullscreen()`，且只操作播放器自身的全屏元素。弹层及对话框仍先处理 Esc；退出全屏立即返回，不同时退出纯净播放。

## 保留行为

- 视频全屏与纯净播放仍是两个独立模式，不恢复已取消的浏览器/页面全屏入口。
- 全屏与退出全屏不更换 video 节点、播放来源或解码实例，不改画质、媒体文件、播放索引和数据库结构。
- 控制栏仍透明、无渐变、无明边框；画中画和视频全屏仍在最右侧。
- 键盘操作不主动显示隐藏的控制栏。深浅色模式使用相同的视频控件对比度策略。

## 验证方式

- 扩展字幕弹层测试：第一次 Esc 关闭菜单，第二次 Esc 退出视频全屏。
- 扩展 Electron 窗口测试：检查退出图标、点击和 Esc 退出、原比例恢复以及纯净播放保留。
- 库分页、分类、收藏、目录、播放列表、字幕、缩放及快捷键等采用现有相关回归用例；使用隔离数据库和合成视频，不操作日常媒体库或源视频。

## 追加精修：控制区鼠标停留

- 原逻辑仅在鼠标移动时重置倒计时，鼠标停住即会再次隐藏。新增控制区鼠标进入/离开标记，并将三处隐藏调度统一为 `scheduleControlsHide`；停留时取消计时，回调执行前再次检查悬停标记。
- 控制栏的进度条、按钮和空白区域均属于保持显示范围；暂停后继续、seek、弹层关闭不会解除悬停保护。移回画面按普通模式 2600ms、纯净/视频全屏 850ms 隐藏，离开播放器按原有 500ms/150ms 加速隐藏。
- 只由鼠标指针边界更新该标记，不用焦点或 CSS `:focus-within` 保持显示；键盘操作仍不会唤醒已经隐藏的控制栏，触摸指针也不会留下鼠标悬停锁。
- 新增四个 UI 用例，验证静止悬停、从隐藏状态进入控制区、播放状态切换、seek、菜单关闭、离开控制区/播放器以及键盘安静播放。
- Electron 窗口模式测试增加桌面端纯净播放的静止悬停检查，并已通过。
- 构建成功，运行时标识 `1e30721c736ab70f`；本轮 39/39 个相关 UI 用例通过（1.8 分钟），`git diff --check` 通过。未打包或推送。
- 初轮 38/39 通过，新增菜单用例在键盘退出纯净播放后直接对隐藏滑块发起 hover，命中透明控制栏的禁用指针状态。测试改为先真实移动鼠标到画面，再操作已显示控件；未强制点击或放宽超时，也未改变键盘隐藏规则。

## 追加精修：暂停状态自动隐藏

- 移除隐藏调度器中 `video.paused` 的例外。播放与暂停都按相同空闲规则隐藏，鼠标停在控制区或菜单打开时继续保持显示；准备播放、续播选择和播放结束状态仍不隐藏操作入口。
- 隐藏时对 `.video-canvas` 同样设置 `cursor:none`，避免普通模式下缩放画面的 grab 光标覆盖父级隐藏光标。
- 新增普通、纯净、视频全屏三个暂停用例：暂停时悬停保持、离开控制区后隐藏、缩放光标隐藏、时间不变、C 键截图及空格恢复/再次暂停不显示隐藏控件、真实鼠标移动重新显示。
- 原菜单用例改为暂停状态验证；桌面测试增加暂停悬停、暂停后移开隐藏控制栏和标题栏、键盘恢复播放仍保持隐藏的检查。
- 构建标识 `677878d69b67765b`；54/54 个相关 UI 回归通过（2.5 分钟），包含外观、字幕弹层、截图、全屏及快捷键。

## 追加精修：原生滚动条自动显隐
